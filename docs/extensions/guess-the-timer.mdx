---
title: Guess the Timer
sidebar_label: Guess the Timer
---

Guess the Timer hides the remaining time on your lock. When you think the lock is ready to open, use the extension's **Unlock** button to make a guess.

If the lock can be unlocked, the extension stops blocking it. If you guess too early, it adds a random amount of time within the range set when the extension was configured. You can try again while the lock is active.

When adding the extension, choose the minimum and maximum time that an incorrect guess can add. The default range is three to six hours.

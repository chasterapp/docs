Because hygiene is important, unlock yourself regularly to clean your chastity device or take a break from your restraints. Be careful, if you exceed the allowed time, you will receive a penalty.

## Introduction

The Hygiene Opening extension allows you to temporarily unlock your lock, to clean your chastity device, or for any other reason. The time between each unlocking is by default two days, and can be modified according to your needs. When you start your lock, you will have to wait for the configured time before unlocking temporarily for the first time.

When you are unlocked, you will have a set time to clean up or whatever, which defaults to 15 minutes. This time includes the time to unlock and relock yourself. If you exceed this time, a penalty will be applied and time will be added, by default 12 hours.

The keyholder can temporarily unlock you at any time.

:::info Bondage locks
Hygiene opening works the same way on [bondage locks](/bondage): during an opening you can remove your restraints, and you must put them back on before the allowed time runs out. With **Request verification picture after opening**, the picture follows the [bondage rules](/extensions/verification-picture#bondage-locks) of the Verification picture extension: it shows your restraints instead of a device.
:::

## Openings on a schedule

Instead of a waiting time between openings, you can choose **On a schedule** to allow openings only at set times, for example every morning between 07:00 and 07:45. An opening started inside a window lasts the full time allowed, even if the window ends in the meantime. See [Schedules](/extensions/schedules).

With "Allow only the keyholder to open the lock temporarily", only the keyholder can start an opening, even inside the scheduled times.

## Options

If you select the option "Allow only the keyholder to open the lock temporarily", you will not be able to unlock yourself temporarily, only the keyholder will be able to do so. Please note that if you do not have a keyholder, you will not be able to use the extension if this option is enabled.

### Verification picture integration

The Hygiene Opening extension can be combined with the Verification Picture extension to add extra accountability:

- **Require verification picture before opening**: The wearer must have submitted a verification picture in the last 15 minutes before they can temporarily open the lock. This ensures the wearer proves they are still locked before being allowed to open.

- **Request verification picture after opening**: A verification picture request will be automatically triggered after the lock is resumed. This helps verify that the wearer has properly relocked after the hygiene opening.

:::note
You need to enable the [Verification Picture extension](/extensions/verification-picture) for these options to have effect.
:::

## New application

In order to use the API, you will first need to create an application. Here are the steps to follow:

1. Open the [Chaster developer interface](https://chaster.app/developers/applications) and log into your account.
2. Click on the "Create an application" button.
3. Enter a name and click on the "Save changes" button.

![Create an application](/img/api-create-application-form.png)

## Delete an application

The owner of an application can delete it from the developer interface:

1. Open the [Chaster developer interface](https://chaster.app/developers/applications) and open your application.
2. In the "Delete application" section, click on the "Delete application" button.
3. Check the list of extensions that will be deleted, then confirm with the "Delete application" button.

![Confirm the deletion of an application](/img/api-delete-application.png)

Deleting an application is permanent. It deletes the application, all of its extensions, and the developer tokens and OAuth access that belong to it. Cleanup finishes shortly after you confirm, so the application can still show up for a few minutes if you reload the page.

Other members of an application cannot delete it. If your application has no owner, contact us to delete it.
